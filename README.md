# 🤖 Agent Studio

Sua plataforma inteligente de agentes de IA para buscar, analisar e interagir com dados de múltiplas fontes.

## 🚀 Features

- 🔍 Busca inteligente multi-fonte
- 📊 Dashboards em tempo real
- 🎮 Integração com jogos
- 💰 Criptomoedas
- 🗺️ Mapas e localização
- 📰 Notícias
- 🌤️ Previsão do tempo
- 🌓 Dark/Light mode
- 🔐 Autenticação social (Google, Facebook)

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Rodar desenvolvimento
npm run dev

# Build produção
npm run build

# Rodar servidor backend
npm run server
